# Сторонние компоненты

Windows-версия использует:

- [Electron](https://www.electronjs.org/), лицензия MIT
- [hls.js](https://github.com/video-dev/hls.js), лицензия Apache 2.0
- [Lucide](https://lucide.dev/), иконки, лицензия ISC
- [Nunito](https://fonts.google.com/specimen/Nunito), шрифт, лицензия SIL Open Font License 1.1

Метод получения музыки повторяет подход проектов [Meridius](https://github.com/PurpleHorrorRus/Meridius) и [EasyVK-AudioAPI](https://github.com/PurpleHorrorRus/EasyVK-AudioAPI).
